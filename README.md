# BULKSTACK
**v2.0 // Programmable Diet**

BulkStack is a modern, dark-themed diet planner designed to help you organize your bulking phase efficiently. Plan your weekly meals, auto-generate shopping lists, and customize your diet modules on the fly.

## 🚀 Features

*   **Weekly Planner**: Granular scheduling for Breakfast, Lunch, Dinner, and Snacks across all 7 days.
*   **Smart Shopping List**: Automatically aggregates ingredients from your weekly plan into a consolidated checklist.
*   **Module Manager**: Create, edit, and delete custom meal templates. Define ingredients once, use everywhere.
*   **Progress Tracking**: Mark meals as completed to stay on track.
*   **Local First**: All data is persisted instantly to your browser's LocalStorage. No login required.
*   **Responsive UI**: Sleek, dark-mode interface optimized for mobile usage.

## 🛠️ Tech Stack

*   **React 19**
*   **Vite**
*   **TailwindCSS 4**
*   **Lucide React** (Icons)

## 📦 Getting Started

1.  **Clone the repository**
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Start the development server**:
    ```bash
    npm run dev
    ```

## 📖 How to Use

### 1. The Planner
*   The home screen shows your weekly schedule.
*   Tap the **Refresh** icon on any meal slot to swap it with another module.
*   Tap the **Check** circle to mark a meal as consumed.

### 2. Shopping List
*   Switch to the **SHOP** tab to see your generated grocery list.
*   The list updates automatically based on your current weekly plan.

### 3. Module Manager
*   Go to the **MANAGE** tab to customize your food database.
*   Add new meals with specific ingredients (comma-separated) to ensure the shopping list works correctly.
